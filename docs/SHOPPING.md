## 🛡️ Nach Erhalt

### Qualitäts-Check:

1. **D1 Mini testen:**
   ```
   - USB-Strom + LED Blink Test
   - Arduino IDE erkannt?
   ```

2. **LEDs prüfen:**
   - Mit 5V + 220Ω → leuchten?

3. **Taster testen:**
   - Drücken/loslassen flutscht?

4. **IR-Sensor:**
   - Mit Multimeter messen?
